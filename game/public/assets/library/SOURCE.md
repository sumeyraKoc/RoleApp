# Library asset sources

The environment map and its PNG tiles were copied from the user-provided
`Downloads/library/Isometric` package. Their original filenames are preserved.

`librarian-npc.png` was generated for this project with OpenAI's built-in image
generation tool. Prompt summary: a friendly, glasses-wearing pixel-art library
manager in a burgundy cardigan, holding one book, on a transparent background;
the existing Praglish player and bakery NPC were used as visual references.
